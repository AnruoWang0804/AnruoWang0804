## 🚀 Current Research

I am currently exploring efficient algorithms and systems for large-scale vector retrieval, with a particular focus on:

- Reducing redundant distance computations during graph search
- Adaptive search strategies for HNSW
- Early termination for approximate nearest neighbor search
- Efficient construction and maintenance of proximity graphs
- Improving the **recall–latency trade-off** of vector search systems
